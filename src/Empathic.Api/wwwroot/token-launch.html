FAQ

No mystery-box tokenomics.

Clear information attracts better long-term supporters than manufactured urgency.

Can I buy EMPATH on this website today?

No. This pre-launch page does not accept money or execute token purchases.

Does 50/50 mean the founders own 50% of the company each?

No. The website's configurable 50/50 values refer only to the displayed founder token-allocation slots. Company ownership is a separate legal matter.

Are the two wallet addresses hard-coded?

No. They are supplied through server environment configuration. The repository contains no private keys or seed phrases.

Will EMPATH increase in price?

No price appreciation or return is promised. A token can lose value or never become publicly tradable.
